# Smart Home Voice Control MVP

This project is a Smart Home Voice Control MVP built using a full-stack approach.

## Features
- Voice command support
- Backend using Node.js
- Frontend built with modern JavaScript tools
- Supabase integration

## Project Structure

├── backend/

│ ├── package.json
│
├── frontend/
│ ├── src/
│ ├── public/
│
└── README.md
